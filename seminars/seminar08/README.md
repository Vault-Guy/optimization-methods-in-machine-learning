# Семинар 8. Предобусловливание

Комплект по лекции 10 курса «Методы оптимизации в машинном обучении». Пять основных задач для работы у доски примерно на 40 минут, пять дополнительных задач и Colab-совместимый ноутбук с десятью программными аналогами. Номера и темы задач в PDF и ноутбуке совпадают. Готовые решения в студенческие материалы не включены.

## Файлы

- `seminar08_theory.pdf` — задачи для решения на бумаге.
- `seminar08_theory.tex` — редактируемый LaTeX-исходник листка.
- `seminar08_computational_tasks.ipynb` — ноутбук с постановками, данными и заготовками кода.
- `make_notebook.py` — генератор ноутбука из читаемых ячеек.
- `requirements.txt` — зависимости ноутбука.

## Темы по номерам

| № | Тема |
|---:|---|
| 1 | Замена координат и предобусловленный шаг |
| 2 | Направление спуска при $P\succ0$ |
| 3 | Спектр, допустимый шаг и скорость |
| 4 | Случай, когда предобусловливатель Якоби помогает или не помогает |
| 5 | Регуляризованный МНК и выбор $P$ |
| 6 | Неопределённый и вырожденный $P$ |
| 7 | Спектральная эквивалентность |
| 8 | Предобусловливатель, ухудшающий скорость |
| 9 | Замена координат и регуляризационный штраф |
| 10 | Диагональный шаг для логистической регрессии |

## Сборка

PDF собирается XeLaTeX:

```powershell
latexmk -xelatex -interaction=nonstopmode -halt-on-error seminar08_theory.tex
```

Ноутбук открывается в Jupyter или Google Colab. Все данные генерируются локально, сетевые запросы не нужны. Для повторного создания ноутбука:

```powershell
python make_notebook.py
```

Перед работой установите зависимости из `requirements.txt`. Ячейки с `TODO` являются заготовками: до заполнения они выполняются без вычисления ответа.
