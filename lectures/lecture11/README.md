# Лекция 11. Метод тяжёлого шарика

Полная презентация курса «Методы оптимизации в машинном обучении»: 56 слайдов, 80 минут. [Готовый PDF](../../pdf/lecture11_heavy_ball.pdf), исходник Beamer и план лекции.

## Содержание

Вывод двухшагового правила, интерпретация скорости, примеры колебаний, точный анализ положительно определённой квадратичной функции, доказательство области устойчивости, вывод и оптимальность параметров Поляка, аккуратная оценка скорости с множителем k, теорема об энергии для общей гладкой функции, локальная сходимость около строгого минимума, практические примеры и переход к методу Нестерова.

## Сборка

Нужны Python 3 с пакетами из корневого `requirements.txt`, а также latexmk и pdfLaTeX. Скрипт создаёт рисунки в `figures/`. Для локальной сборки поместите тему ВШЭ в `HSE-theme/` рядом с исходником; workflow GitHub Actions получает её автоматически.

    python generate_figures.py
    latexmk -pdf -interaction=nonstopmode -halt-on-error lecture11_heavy_ball.tex

Графики создаются исключительно в Python/matplotlib. TikZ не используется.
