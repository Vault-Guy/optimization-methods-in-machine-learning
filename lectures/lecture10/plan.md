## Главные результаты лекции

1. При $x=Sy$ обычный градиентный спуск по $y$ превращается в $x_{k+1}=x_k-\alpha SS^\top\nabla f(x_k)$. При $P=(SS^\top)^{-1}$ это предобусловленный градиентный спуск.
2. Для $P\succ0$ направление $-P^{-1}\nabla f(x)$ строго убывает, если градиент ненулевой.
3. Для квадратичной функции с $A\succ0$ скорость определяет спектр $B=P^{-1/2}AP^{-1/2}$, а не исходный спектр $A$. При $0<\alpha<2/\lambda_{\max}(B)$ метод сходится из любой точки.
4. Оптимальный постоянный шаг на такой квадратичной функции равен $2/(\lambda_{\min}(B)+\lambda_{\max}(B))$. Взвешенная ошибка сжимается с множителем не более $(\kappa(B)-1)/(\kappa(B)+1)$.
5. Для общей функции с нижней и верхней оценками гессиана в метрике $P$ шаг $1/L_P$ даёт оценку $f(x_k)-f^*\le(1-\mu_P/L_P)^k(f(x_0)-f^*)$.
