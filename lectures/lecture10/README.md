# Лекция 10. Предобусловливание и геометрия методов оптимизации

Презентация курса «Методы оптимизации в машинном обучении»: 56 слайдов, 80 минут, семь блоков. [Готовый PDF](../../pdf/lecture10_preconditioning.pdf) и [подробный план](plan.md).

## Исходники

- `lecture10_preconditioning.tex` — редактируемый исходник Beamer.
- `generate_figures.py` — Python/matplotlib-генератор всех восьми иллюстраций.
- `figures/` и `HSE-theme/` создаёт workflow при сборке; копия темы ВШЭ в репозитории не требуется.

## Содержание

Замена координат и выбор матрицы предобусловливания, предобусловленный градиентный спуск, доказательство свойства направления спуска, спектральные условия и скорость на квадратичных функциях, оценка для гладкой сильно выпуклой функции, примеры из регуляризованного МНК и логистической регрессии. Заключительный слайд готовит лекцию 11 о методе тяжёлого шарика.

## Сборка

Workflow `Build course PDFs` генерирует рисунки и собирает PDF автоматически. Для локальной сборки нужны Python 3, пакеты из корневого `requirements.txt`, pdfLaTeX, latexmk и тема ВШЭ рядом с исходником:

```bash
python generate_figures.py
latexmk -pdf -interaction=nonstopmode -halt-on-error lecture10_preconditioning.tex
```
