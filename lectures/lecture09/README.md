# Лекция 9. Метод Ньютона: от градиента к кривизне

Полная презентация курса «Методы оптимизации в машинном обучении»: 56 слайдов, 80 минут, семь блоков. Готовый PDF находится в [`pdf/lecture09_newton.pdf`](../../pdf/lecture09_newton.pdf).

## Состав проекта

- `lecture09_newton.tex` — полный редактируемый исходник Beamer.
- `generate_figures.py` — единственный источник всех семи иллюстраций; графики построены в Python/matplotlib.
- `figures/` и `HSE-theme/` создаются автоматической сборкой. Шаблон ВШЭ загружается из зафиксированной версии.

## Сборка

Требуются Python 3, пакеты из корневого `requirements.txt` и TeX Live с `latexmk`, `pdflatex`, русскими шрифтами, Beamer и PTSans. После загрузки шаблона ВШЭ из корневого workflow, из папки лекции:

```powershell
python generate_figures.py
latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error lecture09_newton.tex
```

В Windows можно запустить `build.ps1`. Шаблон и графики уже включены в проект, поэтому повторная сборка не требует доступа к сети. Графики пересоздаются генератором.

## Математические условия

Локальная квадратичная оценка на слайдах 33–38 требует стационарного минимума с положительно определённым гессианом, равномерной нижней оценки гессиана и его липшицевости на достаточно малом шаре. Из одной лишь дважды непрерывной дифференцируемости выписанная константа `L_H/(2m)` не следует. При `c<1/2` поиск Армихо принимает полный шаг вблизи минимума, поэтому демпфирование сохраняет эту локальную скорость.
