# Лекция №8. Выбор шага в градиентных методах

Финальная математически расширенная редакция (57 слайдов): точный поиск по направлению, спектральные оценки точного шага, ортогональность последовательных градиентов, условие Армихо, поиск с последовательным сокращением и гарантии приближённой стационарности.

Исходники: `lecture08_step_selection_math.tex`. Все иллюстрации создаёт `generate_figures.py` (Python/Matplotlib); для компиляции сперва запустите этот скрипт, затем `latexmk -pdf lecture08_step_selection_math.tex`. Тема ВШЭ берётся из общей автоматической сборки курса.
