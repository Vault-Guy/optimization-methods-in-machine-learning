# Домашние лабораторные

Лабораторные работы курса хранятся по принципу **одна работа — один каталог**.

```text
labs/
  lab01/
    README.md
    lab01_geometry_gd.ipynb
    data/      # при необходимости
    assets/    # при необходимости
  lab02/
    README.md
    lab02_....ipynb
  ...
```

Внутри каталога каждой работы:

- `README.md` — тема, правила выполнения, разбалловка и ссылка на Colab;
- `.ipynb` — студенческий ноутбук;
- `data/` — внешние данные, если они нужны;
- `assets/` — изображения и прочие вспомогательные файлы, если они нужны.

Решения и преподавательские версии в публичный репозиторий не добавляются.
